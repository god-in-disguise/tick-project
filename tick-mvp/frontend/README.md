# Frontend

PWA-first frontend target.

Use the visual and interaction lessons from `../../local-mvp/tick-mvp-local-expo/`, but rebuild against the production API contracts.

Initial screens:

- live trade screen;
- volatility feed;
- active position;
- deposit/withdraw;
- history;
- account/settings.

The chart must remain truthful: real venue ticks only, no fake vertical motion.
